# Dead Code & Clutter Cleaner

## Цель
Очистить кодовую базу от мусора, неиспользуемых импортов, переменных, мертвых функций и закомментированного кода без поломки рабочей логики.

## Алгоритм работы (Workflow)
1. **Статический анализ (для Python):**
   - Проверь неиспользуемые импорты и переменные через терминал: `ruff check --select F401,F841 .` (можно сразу с `--fix`, если это безопасно).
   - Если установлен `vulture`, запусти его для поиска мертвых функций и классов.
2. **Ручная ревизия файлов:**
   - Удали закомментированные блоки старого кода (история хранится в Git).
   - Удали отладочные `print()` или временные логи, забытые при разработке.
   - Удали неиспользуемые переменные, функции и пустые файлы/заглушки.
3. **Защита от поломки (КРИТИЧНО):**
   - **НЕ удаляй** функции, которые регистрируются через декораторы (роутеры, хендлеры, коллбэки, фоновые задачи), даже если у них нет прямых вызовов в коде.
   - **НЕ меняй** бизнес-логику и сигнатуры публичных API.
4. **Проверка:**
   - После зачистки запусти проект или тесты (либо проверь синтаксис через `python3 -m py_compile`), чтобы убедиться, что ни один нужный импорт не задет.
   - Выведи краткий список того, что именно было удалено.
