# ⚡️ Apple Resell Radar (Авито & Юла)

Высокопроизводительный асинхронный Telegram-бот для мгновенного перехвата свежих объявлений по технике Apple с площадок **Авито (Avito)** и **Юла (Youla)**.

---

## 🎯 Ключевые возможности и архитектура

1. **Zero Latency & Конвейер свежести:**
   - Опрос строго **первой страницы** (10–20 верхних объявлений) с сортировками `sort=104` (Авито) и `sort_field=date` (Юла).
   - Фильтр возраста публикации: отсечение любых объявлений старше заданного порога (`MAX_ITEM_AGE_SECONDS=300`, т.е. 5 минут).
   - При обнаружении нового ID лот не ждет окончания цикла скрейпинга, а моментально проталкивается через `asyncio.Queue` в конвейер отправки.

2. **Детекция снижения цен (Price Drop Detection):**
   - Бот отслеживает динамику цен существующих лотов в Redis/памяти.
   - Если продавец опускает цену, формируется алерт `📉 СНИЖЕНИЕ ЦЕНЫ` с перечеркнутой старой ценой: `<s>60 000 ₽</s> ➔ 52 000 ₽ (-8 000 ₽)`.

3. **Фотокарточки объявлений (Photo Cards):**
   - Парсинг обложек и фотографий лотов. Отправка фотокарточек прямо в чат Telegram с инлайн-кнопкой перехода к объявлению.

4. **Умный фильтр АКБ и скидка на замену:**
   - Парсинг процента износа батареи.
   - При АКБ 75–79% бот автоматически дисконтирует лимит выкупа на `-2 500 ₽`.
   - При АКБ < 75% лимит выкупа дисконтируется на `-4 000 ₽` (замена банки с переносом контроллера).

5. **Управление прайсом через Excel (.xlsx):**
   - Команда `/export_prices` выгружает стилизованную таблицу с текущими ценами и статусами.
   - Отправка отредактированного `.xlsx` обратно в чат мгновенно обновляет матрицу цен на лету.

6. **Интерактивное меню (/menu):**
   - Управление поколениями iPhone (iPhone 11–16 Pro Max) инлайн-кнопками с визуальными статусами ✅ / ❌.
   - Просмотр статистики и политики скидок на АКБ.

7. **Атомарная дедупликация (Redis):**
   - Проверка и установка ключа через команду `SET seen:{platform}:{id} 1 EX 172800 NX` (TTL 48 часов).
   - Встроенный resilient fallback на локальный in-memory кэш при отсутствии Redis.

8. **Спуфинг TLS/JA3 и обход блокировок:**
   - Сетевой движок на базе `curl_cffi` с нативной эмуляцией браузерных TLS handshakes (`impersonate="chrome124"`).
   - Пул HTTP/SOCKS5 прокси с циклической ротацией и автоисключением проблемных узлов.

## 🚀 Быстрый старт

### 1. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `BOT_TOKEN`: токен вашего бота от `@BotFather`.
- `TARGET_CHAT_ID`: ID чата, группы или канала, куда отправлять лоты (можно узнать, написав боту команду `/start`).
- `REDIS_URL`: адрес Redis (например, `redis://localhost:6379/0`).

Если используете прокси:
```bash
cp proxies.txt.example proxies.txt
# Добавьте свои HTTP/SOCKS5 прокси
```

### 2. Запуск через Docker Compose (Рекомендуется)
```bash
docker-compose up -d --build
```
Просмотр логов:
```bash
docker-compose logs -f bot
```

### 3. Запуск локально без Docker
```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов
python -m unittest discover tests

# Запуск мониторинга
python main.py
```

## 🧪 Запуск автоматических тестов
В проект включены 19 комплексных автоматических тестов:
```bash
.venv/bin/python -m unittest discover tests -v
```
Наборы тестов:
- `test_regex_parser`: проверка вычленения iPhone 11..16 Pro Max, памяти (64GB..1TB), АКБ, черного списка (копии, блокировки, запчасти) и парсинга относительных дат.
- `test_margin_filter`: оценка маржинальности лотов, умные штрафы за износ АКБ (-2500 / -4000 ₽) и переключение серий.
- `test_deduplicator`: атомарная дедупликация и фиксация снижения цен (Price Drop).
- `test_excel_manager`: экспорт стилизованной таблицы, парсинг пользовательских правок и валидация.
- `test_formatting`: формирование карточек свежих лотов, карточек с понижением цены и заметок об АКБ.
